# HR Analytics Dashboard using Power BI

## Project Overview
This project focuses on analyzing employee data using Power BI. The dashboard provides insights into employee headcount, gender distribution, age groups, countries, business units, and job roles.

## Tools & Technologies
- Microsoft Power BI
- Power Query Editor
- DAX
- Data Visualization

## Data Cleaning
- Checked missing values
- Removed unnecessary columns
- Checked duplicate records
- Changed data types
- Transformed data using Power Query Editor

## Dashboard Analysis
- Employee Headcount Analysis
- Gender-wise Employee Distribution
- Age Group-wise Employee Analysis
- Country-wise Employee Distribution
- Business Unit-wise Employee Analysis
- Job Role-wise Employee Distribution
- Employee Headcount Trend Analysis

## Key Performance Indicators (KPIs)
- Total Employees
- Male Employees
- Female Employees
- Male and Female Percentage

## Dashboard Features
- Interactive Date Filter
- Business Unit Filter
- Country Filter
- Full Name Filter
- Employee Data Export Option

## Project Files
- `HR analysis.pbix` – Power BI dashboard file
- Employee Dataset – Raw employee data
